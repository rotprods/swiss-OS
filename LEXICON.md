| Term | Canonical meaning | Deprecated / unsafe interpretation |
|---|---|---|
| AUTHORITY | State eligible to change canonical operational truth after all required cross-plane gates. | “Latest file”, “latest chat”, “CI passed”. |
| PROPOSED | A candidate decision or artifact with no execution claim. | “Ready”. |
| IMPLEMENTED | Code/contract exists. | “Executed” or “verified”. |
| EXECUTED | The implementation actually ran against its declared target. | “Implemented”. |
| VERIFIED | Defined tests/checks passed against identified evidence. | Generic confidence word. |
| EMPIRICALLY_QUALIFIED | Verified under representative runtime/data conditions with bounded evidence. | “Production proven” without scope. |
| COMPLETE_AUTHORITY | A wave closed with every affected authority plane reconciled. | Numeric target reached. |
| COMPLETE_READ_ONLY | Read-only objective completed; no authority advanced. | Authority completion. |
| SAFE_STOP_CANARY | Canary evidence is valid but promotion is intentionally blocked. | Partial authority. |
| RECONCILE_REQUIRED | Evidence/identity/state is insufficient for terminal authority mapping. | “Probably new”. |
| ACTIVE_CANONICAL | Current authority-backed canonical entity. | Source record, alias or review candidate. |
| NEW_CANONICAL | Pre-authority resolution action proposing a new canonical entity. | An allocated canonical ID. |
| Session | One globally unique execution identity with durable lifecycle events. | Chat window. |
| Claim | Bounded ownership of resource/semantic scope with fencing token. | Informal “I am working on it”. |
| FencingToken | Monotonic takeover discriminator used to reject stale writers. | Timestamp-based optimism. |
| Event | Immutable coordination fact; projections are derived. | Mutable state row. |
| EventWatermark | Latest event boundary included in a projection/ContextPack. | Wall-clock “last updated”. |
| Projection | Disposable derived view rebuilt from durable events/authority. | Source of truth. |
| ContextPack | Hash-pinned resumption bundle derived from current state and projection. | Memory authority. |
| Evidence | Identified artifact/observation supporting a claim with provenance and scope. | Uncited inference. |
| Review-only | Evidence can reduce review space but cannot create terminal mapping/authority. | Soft terminal match. |
| BLOCKED | A genuine dependency prevents justified progress on the scoped objective. | Preferred tool unavailable while safe alternatives exist. |
| DEGRADED_EXTERNAL | External/provider capability missing while safe local/read-only routes remain. | Project failure. |
| SUPERSEDED | Historical truth retained but no longer current. | Deleted history. |
| V2_FINAL | Reserved for coherent architecture + verified kernel + recovery/death/concurrency/security gates. | “The document is written.” |
